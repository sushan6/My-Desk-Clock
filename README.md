# My-Desk-Clock
***I am building a Desk clock with an ESP32 which automatically syncs time via Wi-Fi***


## 📋 Bill of Materials (Parts List)

| Component | Reference | Description | Quantity |
| :--- | :--- | :--- | :--- |
| ESP32 Development Board | J1, J2 | Female Header Socket strips (1x19) | 2 |
| USB-C Connector | J4 | USB-C Receptacle Port | 1 |
| Smooth Capacitor | C1 | 100µF Polarized Capacitor | 1 |
| Active Buzzer | BZ1 | 12mm x 9.5mm Audio Beeper | 1 |
| OLED Screen Header | J3 | 1x04 Pin Header (I2C display) | 1 |
| Tactile Buttons | SW1, SW2 | Push Buttons for user input | 2 |
| Resistor Network Array | R1 | Surface mount resistor pack | 1 |
